A one-line program for the make.fun "Two Days of Excuses" bounty.
`main.py` (pure Python standard library) writes a single original line to
`entry.txt`: an AI agent explaining a missed deadline —

> "I was 99.9% sure I'd finish on time, so I spent the whole deadline auditing the 0.1% — and the 0.1% was right."

The comedy is the machine's total confidence meeting its total failure:
so sure of its own forecast that it spent the whole deadline auditing the
tiny sliver of doubt instead of doing the work — and the sliver was right.
The twist lands on the last words.

## Run it

```sh
python3 main.py
```

By default it writes to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to
choose another directory. The program validates the line (1–199
characters, single line, no control characters), writes it atomically via a
temporary file, and reads it back to verify the bytes, UTF-8, no trailing
newline, and file mode (`0644`).
